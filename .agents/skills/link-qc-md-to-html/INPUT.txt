SKILL: link-qc-md-to-html
WHAT IT DOES: Renders QC Markdown documents to HTML pages, each file independently, with the renderer
that owns its format: TEST-CASES-{feature}.md → TC-REVIEW-{feature}.html (the skill 3/3c review page),
TEST-RUN-REPORT-{feature}.md + BUG-REPORT-{feature}.md → TEST-RUN-REPORT-{feature}.html (the skill 5 run
report), every other QC Markdown file (test-plan.md, TEST-DATA-{feature}.md, notes) → {file}.html in the
same report shell. Deterministic scripts, zero dependencies, never hand-written HTML.

============================================================
INPUT — WHAT YOU MUST PROVIDE
============================================================
REQUIRED (one or more):
  1. A Markdown file path, or a feature folder (specs/NNN-feature/) — every .md in the folder is rendered.

OPTIONAL FLAGS:
  --lang ar|en   page language (default English; a TC page in Arabic needs its strings sidecar)
  --dry-run      parse and validate only; nothing written
  --force        overwrite a page that was edited by hand or rendered by another tool
  --only tc|run|md   limit a folder run to one renderer

PREREQUISITES: Node >= 18. Nothing else — no browser, no MCP, no network.

============================================================
OUTPUT — WHAT YOU GET
============================================================
  Beside each source file:
    TC-REVIEW-{feature}.html         from TEST-CASES-{feature}.md (+ TEST-DATA, Arabic sidecar, review comments)
    TEST-RUN-REPORT-{feature}.html   from TEST-RUN-REPORT-{feature}.md (+ BUG-REPORT, .runs/, review comments)
    {file}.html                      from any other QC Markdown file (test-plan.md, TEST-DATA-*.md, …)
  Chat: one gate line per page (PASS / MISMATCH / BLOCKED / NOT_RUN) with the reason and warnings.
  Every page has reviewer-comment boxes; "Save comments" writes REVIEW-COMMENTS-{page}.md beside the page.

WHEN TO RUN: any time — after /speckit.plan (test-plan.md for the QC Lead review), after /speckit.tasks
(the TC review page), after /speckit.implement (run report, updated test cases), or on demand.
Never required by any other step: the Markdown files are the source of truth.
